# Atlas Core

Atlas Core is the domain-independent common foundation of Atlas.

Video analysis, Global Intelligence, real estate, and future business domains are separate Domain Applications that may use Atlas Core. They are not part of this repository bootstrap.

Future Atlas Core work may address concepts such as Observation, Interpretation, Decision, Revision, Hypothesis, and Knowledge. These concepts are not implemented by ACI-001.

Creating this repository does not approve any Entity specification, database schema, API contract, migration, service, adapter, or AI provider implementation.

Implementation proceeds only through explicitly approved Implementation Tasks.

ACI-001 does not modify existing Domain Application repositories.
